# Gerber production files

Current production package:

`ESP32_CW_TRAINER_V2_Gerber.zip`

The package is intended for a 2-layer FR-4 PCB and should contain the copper, solder mask, silkscreen, board outline and drill files required for fabrication.

Before ordering, inspect the archive in a Gerber viewer and verify the board outline, connector labels, mounting holes and PTH/NPTH drill data.
