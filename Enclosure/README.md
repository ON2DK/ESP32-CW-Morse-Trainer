# Enclosure

This folder is reserved for the 3D-printable enclosure and OpenSCAD source files for the ESP32 CW Morse Trainer V2.

The PCB uses four M3 mounting holes. Before printing a final enclosure, verify the exact dimensions of the physical TFT module, panel connectors, rotary encoder and potentiometer.

The ESP32 antenna area should remain clear of metal and dense wiring inside the enclosure.
