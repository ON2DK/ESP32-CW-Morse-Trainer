# Firmware

Arduino IDE firmware for the ESP32 CW Morse Trainer belongs in this folder.

The hardware is intended for a 38-pin ESP32 DevKit with ESP32-WROOM-32D and an ST7789 240 x 320 SPI TFT.

Before flashing any sketch, verify that its GPIO definitions match the final KiCad PCB revision. Hardware and firmware should always be treated as a matched pair.
