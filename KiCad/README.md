# KiCad source

This folder contains the editable KiCad source package for the ESP32 CW Morse Trainer V2.

Current source archive:

`ESP32_CW_TRAINER_V2_KiCad_Source.zip`

The project uses a 38-pin ESP32 DevKit with ESP32-WROOM-32D. When opening the project on another computer, verify that project-local footprint libraries are available and that KiCad does not replace intentionally selected footprints without review.

After any PCB edit, refill copper zones and rerun DRC and schematic/PCB parity checks before regenerating Gerbers.
